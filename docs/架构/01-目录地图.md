# 目录地图（四仓）

> 采集于 2026-09-21（工作副本快照）。目录用途以代码注释与各仓 README 为准，本图是汇总视图。

## 0. 四仓关系

```
                    +---------------------------+
   PC 管理后台  ---> |                           |
   员工端小程序 ---> |   photography-server      | ---> MySQL / Redis / NATS
   客户端 H5     ---> |   （Go · Gin · 唯一数据源）| ---> ES / MongoDB / XXL-JOB
                    +---------------------------+ ---> Nacos（配置 + 注册）
                                ^                     Jaeger / SkyWalking（链路）
                                | /api 前缀由 Nginx / Vite proxy 剥离
                    三个前端仓各自独立构建、独立部署
```

- 三端只通过 HTTP JSON 契约与后端交互，**不共享代码**；契约以 internal/contract 与声明式路由表为准。
- 三端挂载点：PC 无前缀；小程序管理端 /miniapp；客户 H5 /h5；微信客户区 /wechat；员工端 /wechat/staff。

## 1. photography-server（后端）

```
photography-server/
|-- cmd/
|   |-- server/            # 组合根：main.go（配置加载/初始化/装配/优雅退出）+ bootstrap.go（非生产种子数据）
|   +-- configctl/         # 配置密文 CLI：keygen / encrypt / decrypt / encrypt-file / check
|-- internal/
|   |-- app/               # 依赖容器 App：持有 DB/Redis/NATS/ES/Mongo/Tracer，业务层只依赖它
|   |-- common/            # 通用常量（分页/上传/响应码）
|   |-- config/            # 配置加载：Nacos 拉取 + 环境变量覆盖 + ENCv1 字段级解密 + prod 基线校验
|   |-- contract/          # 接口契约（15 文件）：入参/出参 DTO，service 与 presentation 共用
|   |-- domain/            # 领域纯函数（13 文件）：订单状态机、退款规则、改期、金额、权限点、数据范围
|   |-- enum/              # 业务枚举（4 文件，int 状态位；以 Go enum 为权威口径）
|   |-- infrastructure/    # 基础设施单例（8 文件）：mysql/redis/nats/es/mongodb/xxljob/jaeger/nacos
|   |-- job/               # XXL-JOB 任务注册
|   |-- middleware/        # CORS/Recovery/RequestLog/Params/Auth/ClientAuth/StaffAuth/Perm/OperationLog/AssetAuth/Trace
|   |-- model/             # 数据模型（11 文件）：统一 Base 5 字段 + TenantBase.company_id
|   |-- mq/                # NATS 消费者（订单状态/通知等异步链路）
|   |-- pkg/               # 中立基础能力（各层可依赖，自身不依赖业务）
|   |   |-- authcache/     #   鉴权画像缓存
|   |   |-- errs/          #   错误类型 + 业务错误文案常量（全仓唯一出口）
|   |   |-- jwtpkg/        #   员工/客户 JWT 签发与校验
|   |   |-- logger/        #   日志封装
|   |   |-- params/        #   参数取值（统一 JSON body 语义）
|   |   +-- response/      #   统一响应原语 Body/Page/OK/PageOK/Fail/File
|   |-- presentation/      # 外围 HTTP 接入层
|   |   |-- bind/          #   BindJSON / PathID / BodyID / Pager / ParamStr
|   |   |-- controller/    #   PC 与小程序管理端控制器（按域分文件）
|   |   |-- endpoint/      #   端装配机制 Endpoint / Mount / MountTable
|   |   |-- h5/            #   客户 H5 控制器（handler 实现 + 端内辅助）
|   |   |-- routes/        #   声明式路由表（Common + ClientPublic/ClientAuthed）
|   |   +-- wechat/        #   员工端独有 handler + 端 Controller
|   |-- repository/        # 数据访问层（24 文件）：WithTx 事务透传 + company_id 租户过滤
|   |-- router/            # 路由装配（8 文件）：端声明、中间件、静态资源、Swagger、调试路由
|   +-- service/           # 业务编排层（39 文件）：只经 repository/domain 访问数据
|-- config/
|   |-- config.yaml / config.example.yaml   # Bootstrap（仅 Nacos 连接段）
|   |-- nacos/             # Nacos 发布模板（dev/test/docker.dev/prod 四份）
|   +-- *.example.yaml / *.example.conf     # jaeger / horizon / nats 模板
|-- docs/
|   |-- 架构/              # ★ 本目录（跨仓架构基线）
|   |-- rbac/              # 权限点手册 / 运维手册
|   |-- sql/               # ddl.sql / dml.sql + 增量链 + initdb（第三方组件库表）
|   |-- swagger/           # Swaggo 生成物（docs.go / swagger.json / swagger.yaml）
|   +-- 部署/              # 容器化部署方案与流程
|-- scripts/               # nacos_init.sh / nacos_publish.sh
|-- build/agent/           # SkyWalking Go agent 二进制（离线构建需要，有意入库）
|-- bin/ uploads/ .nacos/  # 构建产物 / 运行时上传 / Nacos 快照（.gitignore，不入库）
|-- Dockerfile · docker-compose.yml · Makefile · .swaggo · .env.example
+-- README.md
```

### 后端分层（依赖方向单向：外层 -> 内层）

```
cmd/server（组合根）
  +-> internal/app（依赖容器）-> internal/infrastructure（基础设施单例）
presentation（controller/h5/wechat/routes/endpoint/bind）· router · job · mq
        | 只能向下依赖
        v
service（业务编排）-> repository（数据访问）-> model / domain / enum
中立层（各层可依赖）：contract · pkg/{errs,logger,params,response,jwtpkg,authcache}
```
